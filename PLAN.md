# Project and Repository Plan

## Part 1: Project Plan

### Goal

Create a reproducible data analysis report based on HW #4.3 and make sure the report can be reproduced by other users.

### Needs

- R and RStudio
- Quarto
- ggplot2, dplyr, tidyr, knitr, and readr packages
- Diamonds data
- NCAA women's basketball data
- Calcium data
- Original QMD and PDF files

### Steps

1. Review the original HW #4.3 report.
2. Check all required data files.
3. Review the descriptive statistics for the Diamonds data.
4. Review the Big Ten basketball visualization.
5. Check the four Monte Carlo simulation plots.
6. Review the calcium visualizations and comparisons.
7. Check the YAML header and code chunk options.
8. Make sure the coding style is consistent.
9. Check all relative file paths.
10. Render the QMD file into a PDF.
11. Review the final report for errors.

## Part 2: Repository Management Plan

### Goal

Create and maintain a public GitHub repository that contains all necessary files for the reproducible data analysis project.

### Needs

- GitHub account
- GitHub Desktop
- RStudio
- Public GitHub repository
- README and plan documents
- QMD, PDF, and necessary data files

### Steps

1. Create a public GitHub repository.
2. Clone the repository to my computer.
3. Create and publish a dev branch.
4. Create issues to organize the remaining tasks.
5. Complete the README file.
6. Create a separate plan document.
7. Add the project files.
8. Review and improve the QMD file.
9. Create commits.
10. Reference related issues in the commit messages.
11. Push the changes to GitHub.
12. Create a pull request to merge dev into main.
13. Close the completed issues.
14. Check that the main branch is up to date.
15. Submit the repository URL to MyOpenMath.
